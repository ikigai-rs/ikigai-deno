# AGENTS.md

`ikigai-ts` is a TypeScript client and servable peer for the ikigai wire
protocol, running on Deno, Node and Bun.

- Read [ACCESSIBILITY.md](ACCESSIBILITY.md) before any change to output people
  read: messages, pages, terminal text.
- Run `just gates` (the `deno.json` tasks CI runs) before opening a pull
  request.
- Security reports go through
  [private vulnerability reporting](https://github.com/ikigai-rs/ikigai-ts/security/advisories/new),
  never a public issue.
- Write American spelling (behavior, color, labeled).
